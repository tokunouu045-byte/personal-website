# 智旅 App · AI 产品经理作品集文档使用说明

本文件夹是一套围绕「智旅 App（AI 旅行规划助手）」Axure 原型整理的求职作品集文档，定位为 **AI 产品经理岗位**。所有内容均基于原型真实页面与功能整理，目标数据均标注为「规划口径 / 示例」，请在投递前替换为实际数据。

## 文档清单与用途

| 文件 | 用途 | 建议使用场景 |
| --- | --- | --- |
| 01-作品集项目概览-智旅App.docx | 项目一句话介绍、角色、亮点、指标、复盘、面试速览 | 简历附件、面试开场介绍、作品集首页 |
| 02-智旅App-PRD产品需求文档.docx | 完整 PRD：背景、用户、功能需求、流程、指标、版本规划 | 展示需求分析与文档能力，可单独投递 |
| 03-智旅App-AI功能设计说明.docx | AI 场景设计：行程规划、攻略生成、Prompt 思路、评估体系、数据飞轮 | AI 产品经理重点加分项，建议面试前熟读 |
| 04-智旅App-交互设计说明.docx | 页面明细、核心流程、23 张原型缩略图、状态设计 | 展示交互理解，配合 Axure 原型演示 |
| 05-智旅App-竞品分析与市场机会.docx | 竞品格局、功能对比、差异化定位、进入策略 | 展示市场分析与产品判断力 |
| assets/pages/ | 原型页面缩略图（交互设计说明内已内嵌） | 可复用为 PPT / 简历插图 |

## 投递前必改

1. 把 5 份文档中的「（替换为你的姓名）」替换为真实姓名。
2. 把「示例 / 规划口径」数据（如首次规划完成率 ≥ 60%）替换为真实数据，或删除目标数字、只保留指标框架。
3. 如你有更多背景（实习/项目/竞赛），可在「我的角色」「项目复盘」中补充真实经历。
4. 正式投递建议将 .docx 导出为 PDF，并在面试时打开 Axure 原型配合演示。

## 建议的投递组合

- 简历 + 01（项目概览）＋ 02（PRD）→ 通用投递
- 简历 + 01 + 03（AI 设计说明）→ 投 AI 产品经理 / AI 应用产品岗
- 简历 + 01 + 02 + 03 + 04 + 05 → 完整作品集（面试前发送）
